# 🎬 Movie Search App



This is a simple and fun movie search application built with **HTML**, **CSS**, and **JavaScript**. It lets you search for movies by title and shows the results with poster images and titles. All done with vanilla JavaScript — no frameworks!

## 🚀 Features

- Search for any movie by name
- Display results dynamically
- Fallback placeholder for missing data
- Clean and responsive UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 📁 How to Use

1. Clone the repo
   'bash https://github.com/SebbastianMartins/Buscador_de_Peliculas'
   git clone 


 2. Open index.html in your browser

That's it! You’re ready to search movies.
